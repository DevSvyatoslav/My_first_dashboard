# AI Agents Dashboard 🚀

> Интерактивный дашборд для мониторинга вымышленной сети ИИ-агентов. Проект создан как часть моего портфолио для демонстрации навыков фронтенд-разработки.

![Скриншот дашборда](img width="1346" height="572" alt="изображение" src="https://github.com/user-attachments/assets/00b9ebd7-8081-4e47-9318-785e3dc789d8)

## 📋 О проекте

Этот проект — моя попытка собрать красивый и функциональный дашборд, вдохновлённый интерфейсами реальных SaaS-продуктов (например, Plecto). Мне было интересно разобраться, как работают «живые» данные, светлая/тёмная тема и переключение языков на настоящих сайтах.

Проект написан на **чистом HTML, CSS и JavaScript** — без фреймворков.

## ✨ Что умеет

- **Адаптивная сетка** — карточки и таблица сами перестраиваются под ширину экрана (от телефона до монитора).
- **Светлая / тёмная тема** — переключается кнопкой, выбор сохраняется (через `localStorage`).
- **Переключение языка RU / EN** — все заголовки, карточки и шапки таблицы переводятся на лету.
- **Динамический пинг** — значение в карточке «Средний пинг» обновляется каждые 2 секунды. Цвет меняется от зелёного к оранжевому и красному в зависимости от нагрузки.
- **Таблица ботов** — данные рендерятся из массива объектов через JavaScript, а не прописаны в HTML вручную.

## 🛠 Технологии

- **HTML5** — семантическая разметка (`header`, `main`, `section`, `article`, `table`).
- **CSS3** — Grid, Flexbox, CSS-переменные для тем, `@media` для адаптивности.
- **JavaScript (ES6)** — `forEach`, шаблонные строки, `classList`, `setInterval`, `addEventListener`, работа с `localStorage`.
- **Chart.js** — *в планах*. Хочу заменить статичную цифру CSAT на круговую диаграмму.

## 🚀 Как запустить

Проект не требует сборки или установки зависимостей.

1. Скачай или клонируй репозиторий:
   ```bash
   git clone https://github.com/DevSvyatoslav/ai-agents-dashboard.git
   ```
2. Открой `index.html` в браузере — и всё.

Либо просто открой мой сайт на **GitHub Pages**.
